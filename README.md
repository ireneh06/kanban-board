# Kanban Board

Ein einfaches Kanban-Board zum Üben von React.

## Funktionen

- Aufgaben erstellen, bearbeiten und löschen
- Aufgaben zwischen den Status-Spalten per Drag-and-drop verschieben
- Aufgaben direkt der passenden Spalte zuordnen
- Aufgaben im Browser mit `localStorage` speichern

## Voraussetzungen

- Node.js
- npm

## Lokal starten

```bash
npm install
npm run dev
```

## Datenspeicherung

Aufgaben werden im `localStorage` des  Browsers gespeichert. Sie sind nur in diesem Browser auf diesem Gerät verfügbar. Das Löschen der Browserdaten kann gespeicherte Aufgaben entfernen.
